# Technosignia Data Analyst Internship – Day 11 to Day 15

## Introduction
This repository contains practical tasks completed as part of my Data Analyst internship training at Technosignia. It documents my learning and hands-on work in data visualization, Power BI dashboards, exploratory data analysis, SQL, and machine learning fundamentals.

## Day 11 – Data Visualization
**Tools:** Python, Matplotlib, Seaborn

**Topics Covered:**
- Bar charts and line charts
- Histograms and box plots
- Scatter plots and correlation heatmaps
- Chart titles, axis labels, legends, and scales
- Interpreting charts and identifying business insights

**Learning Outcome:** Learned how to visualize data, identify patterns, and communicate observations using charts.

## Day 12 – Excel and Power BI Dashboard
**Tools:** Microsoft Excel, Power BI, Power Query, DAX

**Work Completed:**
- Imported and reviewed a sales dataset containing 1,200 rows and 14 columns.
- Checked data quality and column information.
- Created DAX measures for Total Sales, Total Profit, and Total Orders.
- Designed KPI cards, a category-wise sales bar chart, and a monthly sales trend line chart.
- Added Region and Category slicers for interactive analysis.

**Dashboard:** Sales Performance Analysis Dashboard

**Learning Outcome:** Practiced data preparation, DAX measures, and interactive dashboard development.

## Day 13 – Python Exploratory Data Analysis (EDA)
**Tools:** Python, Pandas, Matplotlib, SQLite

**Work Completed:**
- Loaded and explored the sales dataset.
- Checked data types, missing values, and duplicate records.
- Prepared data for analysis.
- Used SQL queries to summarize sales and profit.
- Created charts for regional sales, category sales, and monthly sales trends.

**Business Questions Explored:**
1. Which region generates the highest sales?
2. Which product category generates the highest sales?
3. How do sales change over time?
4. Which customer segment generates the highest profit?
5. Which payment method has the highest sales amount?

**Learning Outcome:** Practiced data cleaning, SQL-based analysis, and communicating business findings through visualizations.

## Day 14 – Machine Learning Fundamentals
**Tools:** Python, Pandas, Scikit-learn

**Work Completed:**
- Used the Iris dataset for a classification exercise.
- Split the data into training and testing sets.
- Trained a Decision Tree Classifier.
- Evaluated the model using accuracy, precision, recall, F1-score, and a classification report.
- Generated a prediction using sample flower measurements.

**Learning Outcome:** Understood the basic classification workflow, model evaluation, and prediction.
